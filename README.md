# flyABBI Rock Band Website

This repository contains the static website for the flyABBI rock band and community campaign experience.

## Project Structure

- Homepage Code/index.html — landing page and site highlights
- Music/index.html — music section
- Tour/index.html — tour dates and event feed
- Cause/index.html — cause and support initiatives
- Arenas/Dashboard.html — dashboard experience
- Arenas/Onboarding.html — onboarding checklist
- Global Style Code/style.css — shared styling and layout

## Local Development

You can serve the site locally with Python's built-in HTTP server:

```powershell
python -m http.server 8080
```

Then open:

http://localhost:8080/Homepage%20Code/index.html

## GitHub Pages

The static files are designed to be hosted as a GitHub Pages site or served locally through a web server.
